# AI Portfolio Assistant

An intelligent chatbot assistant that helps recruiters and visitors learn about Drishti Chaudhary's background, skills, and experience through natural conversation.

🔗 **Live Demo:** [AI Portfolio Assistant](https://drishtichaudhary.github.io/ai-portfolio-assistant/)  
📂 **Repository:** https://github.com/drishtichaudhary/ai-portfolio-assistant

---

## Overview
This project was built to **create an interactive, AI-powered interface for portfolio engagement** while working with **modern web technologies, cloud functions, and large language models**.  
It reflects a hands-on approach to learning and building practical AI solutions that enhance user experience.

---

## Features
- Real-time AI-powered conversation about Drishti's professional background
- Context-aware responses grounded in resume and portfolio information
- Modern dark theme UI with DM Mono monospace font
- Responsive design optimized for desktop and mobile
- Cloudflare Worker backend for scalable API handling
- Integration with Groq's Llama model for intelligent responses

---

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Frameworks / Libraries:** Google Fonts (DM Mono, Inter)
- **APIs / Tools:** Groq API (Llama 3.1-8b-instant), Cloudflare Workers

---

## What I Learned
- Integration of serverless functions with LLM APIs for real-time applications
- CORS handling and API security in cloud environments
- Modern UI/UX design principles with monospace typography
- Error handling and debugging in distributed systems
- Frontend-backend communication patterns for AI applications
